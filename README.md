# Vibe Check

一个面向 Vibe Coding 作品的趣味 AI 鉴定网页。  
导入项目材料，使用自己的 AI API Key，生成带六维评分、证据等级、屎山指数和改进建议的可视化鉴定报告。

> **有依据地夸，讲人话地吐槽。** 这是一份帮助你重新审视作品的参考报告，而不是专业代码审计。

## 功能

- **两种使用方式**：直接复制或下载 Markdown 鉴定提示词，交给自己常用的 AI / Agent；也可以在网页内使用 BYOK 模式生成可视化报告。
- **多种材料导入**：支持上传源码文件、文件夹、ZIP 压缩包，粘贴代码或项目说明，以及导入公开 GitHub 仓库；也可提供截图供支持视觉理解的模型参考。
- **两种鉴定策略**：智能源码核验模式从本地全文索引中抽取原始代码并回查疑点；传统模式逐段阅读材料并补充源码窗口复核。大项目的鉴定耗时、请求次数与费用会因策略和模型而异。
- **趣味鉴定报告**：六维评分、A/B/C/N 证据等级、屎山地形勘察、值得夸与值得修的地方、撞衫与自嗨观察，以及下一步建议。支持调整点评辣度。
- **本地历史档案**：成功生成的报告自动保存在当前浏览器中，可查看、筛选、删除并导出 TXT；记录提交时填写的作品名称与补充背景，方便事后复核。
- **自备 AI（BYOK）**：提供 DeepSeek、Kimi、智谱 GLM、阿里云百炼、OpenAI 及兼容接口的配置入口，允许手动修改 API 地址和模型名称，并测试连接。

## 使用方式

本项目为**单文件静态网页**，HTML 内包含所需的 CSS 和 JavaScript，不需要安装依赖，也不需要自建后端。

1. 打开部署后的网页，或直接在浏览器中打开 `index.html`。
2. 在「获取提示词」中复制完整提示词，自行交给 AI 使用；**或**在「作品鉴定实验室」填写作品信息并导入材料。
3. 如果使用 GitHub 导入，请粘贴**公开仓库**地址并点击「导入」，等待源代码读取成功。只粘贴网址并不等于完成导入；访问 GitHub 可能需要适当的网络环境。
4. 选择鉴定策略、模型服务商，填写自己的 API Key，按需测试连接后提交鉴定。
5. 查看报告，并按需导出 TXT 或在本地历史档案中留存。

### GitHub Pages 部署

如果将本项目部署在 GitHub Pages：

1. 创建名为 `vibe-check` 的仓库。
2. 将最新单文件 HTML **重命名为 `index.html`**，连同本 `README.md` 上传到仓库根目录。
3. 在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，指定 `main` 分支和 `/(root)` 目录。
4. 等待 GitHub Pages 部署完成，再打开对应网页地址。

使用 GitHub Pages 只需要静态文件托管；是否能够直接调用模型 API，仍取决于对应服务商的浏览器跨域（CORS）支持。

## 本地数据与 API Key

- 本站不提供账户系统、云端报告同步或自建的模型请求中转服务。
- 项目文件先由浏览器在本地读取、筛选与处理；**点击提交鉴定后，选中的源码材料或代码片段、作品名称和补充背景会被发送至用户选择的 AI 服务商**。请勿提交不愿与该服务商共享的内容。
- API Key 由用户自行填写。默认无需保存；如果主动勾选「记住 Key」，密钥会以**未加密明文**保存在该浏览器的 `localStorage` 中，并可在页面内一键删除。不要在公共或不可信设备上保存密钥。
- 鉴定报告及提交背景快照同样保存在浏览器本地，**未加密**；导出的 TXT 也可能包含用户填写的背景信息。请勿在输入框填写密码、私钥等敏感资料。
- 更换浏览器或设备不会自动同步历史档案；清理浏览器站点数据后，本地记录可能丢失。重要报告请及时导出。
- 调用第三方 AI 可能消耗 API 额度并产生费用，具体以对应服务商的规则为准。本项目不代售模型额度。

## 鉴定边界与注意事项

- **趣味评价不等于事实裁决**。AI 可能遗漏上下文、误读函数调用关系，或对产品完成度作出没有充分依据的推断。报告中的分数、段位和屎山指数仅供参考。
- 智能模式会在浏览器里检索全部已导入文本，但默认只把**抽取的原始源码窗口**发送给模型，不能视为完整逐行审阅；传统模式尽管会分段送检，也不代表已经运行或实际测试过项目。
- A/B/C/N 证据等级和「待核验」标记用于提示证据充分程度。涉及安全漏洞、数据损坏或重要重构时，应由开发者或具备实际执行、复核能力的工具进一步验证，**不要仅凭报告就直接大规模改动源码**。
- 为降低意外泄露风险，导入时会过滤部分常见敏感文件并尝试脱敏，但自动识别无法保证万无一失；请自行检查材料。
- 大型项目可能受到文件体积、模型上下文、输出长度、网络超时和 API 限额影响。若返回失败或 N/A 较多，可缩小材料范围、调整模型或选择其他鉴定方式。
- GitHub 仓库导入只支持公开仓库；接口请求可能受到 GitHub 访问限制、网络环境及模型服务商 CORS 策略的影响。
