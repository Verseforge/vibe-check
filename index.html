隐私说明

透明说明资料如何在浏览器中处理和发送

本地读取：源码、ZIP 与截图在浏览器本地读取。智能模式还会本地索引、抽样与回查代码；本站没有接收材料的专门后端。

GitHub：公开仓库导入会向 GitHub API 与 Raw 内容服务器发起请求。

AI 请求：点击鉴定后，浏览器会依策略将部分或全部源码、背景介绍和图片发送至你选定的模型服务商；智能模式不会发送全部源码。

密钥：默认只在当前页使用；勾选记住后会以明文写入本机 localStorage，可在配置区域一键删除。

报告与提交快照：成功鉴定会自动保存报告及你当时填写的“作品名称”“补充背景”原文（包含其中的任何指令性文字），供后续溯源。内容以明文存于本机 localStorage，并可导出到 TXT；可以单条或全部删除。不要填写密钥、隐私内容。清除站点数据也可能删除记录。

敏感信息：项目内容会尝试跳过常见敏感文件并做简单脱敏，但无法保证完全识别。上传前请自行检查。
